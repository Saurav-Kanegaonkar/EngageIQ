How Trends integrates with the dashboard — four layouts

Grounded in the research: tabs = distinct pages · side-panel = always-visible · overview→drill = progressive disclosure. Real graphs shown in context.

OPTION 1
Top tabs (separate pages)

One persona space, switch pages: Opportunities / Trends / Activity. Each gets full real estate. Cleanest separation; you see one at a time. (Pattern: top-level tabs.)
